# Smart Exam Portal

PDF Analysis & Assessment System for All Departments.
Developed by Akhilesh Patidar (AE) — er.akhileshpatidar@gmail.com

## Files
- index.html — the complete portal (single file)
- sw.js — offline service worker (needed for the Chrome "Install app" button)

## Hosting on GitHub Pages
1. Create a new public repository.
2. Upload index.html and sw.js to the root of the repository.
3. Settings > Pages > Branch: main, Folder: / (root) > Save.
4. Open the generated https://<username>.github.io/<repo>/ link in Chrome — the Install button appears.
